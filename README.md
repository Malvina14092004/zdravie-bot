# Zdravie Bot 🩺

Telegram-бот-помощник по вопросам здоровья. Отвечает на справочные вопросы пользователя с помощью ИИ (через OpenRouter), при этом всегда напоминает, что ответы не заменяют консультацию врача.

## Как работает
Бот принимает сообщения через Telegram Webhook API. При команде `/start` присылает приветствие. На остальные сообщения формирует запрос к OpenRouter (модель GPT) с системным промптом, ограничивающим бота ролью справочного помощника по здоровью, и отправляет ответ пользователю обратно в Telegram.

## Технологии
- PHP
- Telegram Bot API
- OpenRouter API (доступ к GPT-моделям)
- cURL

## Установка и запуск

\`\`\`
git clone https://github.com/Malvina14092004/zdravie-bot.git
cd zdravie-bot
\`\`\`

Создай файл `.env` (или настрой переменные окружения на сервере) с ключами:
\`\`\`
BOT_TOKEN=токен_из_BotFather
OPENROUTER_KEY=ключ_с_openrouter.ai
\`\`\`

Разверни `index.php` на сервере с публичным HTTPS-адресом и установи webhook для бота:
\`\`\`
https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://твой-сервер.ru/index.php
\`\`\`

## Функционал
- команда `/start` — приветствие
- любой другой текст — ответ от ИИ по теме здоровья
- обработка ошибок при недоступности OpenRouter API
